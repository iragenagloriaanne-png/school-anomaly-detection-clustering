# School Anomaly Detection and Clustering

## Overview
This project is part of Computing Intelligence Lab 2. It analyzes school installation data across 47 counties in Kenya using Python.

## Objectives
- Clean and prepare the dataset.
- Detect unusual installation patterns using Isolation Forest.
- Group similar counties using K-Means clustering.
- Visualize and interpret the results.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and Kaggle Notebook.

## Results
Isolation Forest identified 5 anomalous counties, while K-Means grouped the 47 counties into 2 clusters.
